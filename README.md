# Depth AI Chat

Windows x64 설치파일과 자동 업데이트를 제공하는 공개 배포 저장소입니다.

**[⬇ 최신 설치파일 다운로드 · Windows x64](https://github.com/depthasset-byte/codex-chat-releases/releases/latest/download/DepthAIChat-Setup-x64.exe)**

클릭하면 설치파일이 바로 다운로드됩니다. [버전별 변경 사항 보기](https://github.com/depthasset-byte/codex-chat-releases/releases/latest)

- 처음 한 번 Setup.exe를 설치하면 이후 앱 왼쪽 아래 버전·업데이트에서 새 버전을 적용할 수 있습니다.
- AI 작업·승인·로그인 중에는 업데이트를 보류합니다. 적용할 때 대화를 저장하고 재시작합니다.
- 같은 PC의 대화·설정·연결 정보는 사용자 AppData에 보관합니다. 다른 PC에서는 본인 AI 계정으로 로그인해야 합니다.
- Codex·Claude 기본 연결 도구가 포함되어 있습니다. 별도 CLI 설치 없이 연결 설정에서 각자 계정으로 로그인하세요.
- Claude 브라우저가 열리지 않으면 로그인 브라우저 열기·로그인 링크 복사를 사용하세요. 인증 코드가 표시되면 앱에 입력할 수 있습니다.
- DeepSeek는 연결 설정의 DeepSeek 카드에 API 키를 붙여넣고 키 연결을 누릅니다.
- Windows 코드 서명 인증서는 아직 적용하지 않았습니다. 설치 시 알 수 없는 게시자 안내가 표시될 수 있습니다.

이 저장소에는 앱 설치파일과 업데이트 정보만 배포합니다. 개발 소스와 개인 로그인 정보는 포함하지 않습니다.
